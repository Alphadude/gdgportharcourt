## 7. Anchor Text Distribution & Link Hygiene

To prevent Google Penguin over-optimization filters, follow an organic, natural anchor text distribution:

```
┌────────────────────────────────────────────────────────┐
│  Anchor Text Distribution Strategy                     │
├───────────────────────────────┬────────────────────────┤
│  Category                     │  Percentage            │
├───────────────────────────────┼────────────────────────┤
│  Branded (DevFest Port Harcourt)│  55%                 │
│  Naked URLs (gdgportharcourt.com.ng) │ 25%             │
│  Topical / Semi-Generic (tech conference, register) │ 15% │
│  Exact Keyword (developer conference Nigeria) │ 5%     │
└───────────────────────────────┴────────────────────────┘
```

### Link Hygiene Guidelines:
1. **Never buy bulk PBN backlinks or fiverr links:** These trigger algorithmic manual actions and degrade indexing.
2. **Always secure contextual editorial links:** Backlinks embedded within genuine editorial paragraphs perform 10x better than footer or sidebar sitewide links.
3. **Monitor 404s & Broken Inbound Links:** Run monthly Google Search Console crawls; set 301 redirects immediately if any URL slug is modified.
