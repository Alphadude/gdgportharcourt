# DevFest Lagos 2025 Clone

## Font Note
The `app/layout.tsx` references `public/fonts/Akira.otf`.
This is the **Akira Extended** display font used in the hero.

### How to get it:
1. Download Akira Extended from https://www.dafont.com/akira-expanded.font
2. Place the `.otf` file at `public/fonts/Akira.otf`

### Temporary fallback:
If you don't have the font, Next.js will fall back to "Arial Black" which 
is close enough for development. The font-variable will still work.
